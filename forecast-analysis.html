Forecast Analysis · PepsiCo

Removing a bottleneck between forecast analysts and data scientists.

Forecast analysts had the domain knowledge to improve forecasts but depended on data scientists for routine experiments. I designed a self-service tool that hides the complexity while keeping the analytical power.

Role
Primary UX designer
Timeline
Jul 2024 – Feb 2025
Team
Product, UX, engineering, stakeholders

In 30 seconds

Problem

Analysts waited on data scientists before they could run routine experiments.

Insight

Analysts knew what they needed; they lacked an interface to do it.

Approach

A structured experiment-request flow and self-service analysis tools.

Intended result

Analysts work independently; data scientists focus on improving models.

The experience model

The reframe

Abstract the complexity, keep the power.

A simplified tool would have been easy to build and useless to experts. The design keeps the controls analysts need for experiments and configuration, and hides the implementation details they shouldn’t have to manage.

Demo videos and detailed workflow screens are confidential. Ask for a walkthrough.
