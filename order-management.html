LONG STORY SHORT

How can we eliminate manual order submission methods (email, fax, PDF) that prevent automation and create tracking nightmares?

Currently food vendors can email, call, even fax orders to PepsiCo for large orders of products.

This dated process severely limits automation, creates tracking issues, and requires constant manual intervention.

With a complex system, short timeline, and lots of constraints, this was a high-tension project that needed a modern solution.

→ KEY PAIN POINTS

  • No standardization: Each order format is different, requiring manual interpretation and data entry
  • Communication gaps: Sales reps and plants operate in silos, leading to miscommunication and delays
  • Time waste: Hours spent on manual data entry that could be automated

→ KEY INSIGHT

The core problem wasn't just the manual methods—it was the lack of a centralized system.

A web-based solution could standardize order submission, enable real-time tracking, and facilitate communication between all stakeholders.

SOLUTION

A web application for submitting and managing orders that enables automation, provides real-time tracking, and improves communication between plants and sales representatives.

The solution standardizes order submission while maintaining flexibility for different customer needs.

Key benefits:

  • Reduced manual data entry
  • Improved order accuracy
  • Enhanced visibility throughout the order lifecycle
  • Streamlined communication channels

→ ORDER MONITORING

A comprehensive screen for viewing all orders and their current statuses in one centralized location.

Users can navigate through orders with powerful filters to personalize their views, making it easy to find specific orders, track progress, and manage workflows efficiently.

→ MODIFICATION REQUEST TRACKING & CREATION

A centralized hub for managing all order modifications in one place.

Users can view all modification requests, track their status, and create new requests seamlessly—providing complete visibility and control over order changes throughout the process.

→ CREATING A NEW ORDER

A streamlined workflow for creating orders directly within the tool when needed.

This feature eliminates the need for external order submission methods, allowing users to input order information directly into the system with a structured, standardized format that ensures accuracy and consistency.

REFLECTION

→ CHALLENGES

The complexity of the existing order system and the short timeline created significant pressure.

Balancing the ideal user experience with technical constraints and business requirements required constant negotiation and prioritization.

Working with multiple stakeholder groups with different priorities and needs required careful communication and alignment to ensure the solution addressed everyone's core concerns.

→ WHAT I LEARNED

Designing for complex business problems made me realize how important it is to ask questions and have a holistic view of every change and requirement given.

When moving into new markets, learning how to balance when to customize to fit a requirement versus understanding if something already built can fit the requirement.

Learning how to balance engineering feasibility and when to advocate for the designs versus make changes based on engineering constraints.
